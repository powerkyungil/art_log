# Art Log

작가 활동·미션 제출 관리 시스템의 가벼운 Node.js MVC 구현입니다.

## 기술 스택

- Node.js
- Express
- EJS
- SQLite (Node.js 내장 모듈)
- Vanilla JavaScript

별도 DB 서버, PHP, Apache가 필요하지 않습니다. `database/art_log.sqlite` 파일 하나가 로컬 데이터베이스입니다.

## 시작하기

```bash
npm install
cp .env.example .env
npm run db:setup
npm run dev
```

기본 관리자 계정은 `.env`의 `ADMIN_LOGIN_ID`, `ADMIN_PASSWORD` 값으로 생성됩니다.

- 관리자: http://localhost:3000/admin/login
- 작가: http://localhost:3000/에서 작가명으로 로그인

작가 계정은 등록 시 작가명이 아이디로 사용되고 비밀번호가 `1234`로 설정됩니다. 작가는 로그인 후 비밀번호를 변경할 수 있으며, 관리자는 작가 상세 화면에서 비밀번호를 `1234`로 초기화할 수 있습니다.

## 로컬 DB

기본 DB 파일은 `database/art_log.sqlite`입니다. 다른 위치를 사용하려면 `.env`의 `DB_FILE`만 수정합니다.

## 공통 미션

모든 미션은 활동중인 전체 작가에게 공통으로 노출되고 제출할 수 있습니다. 관리자 미션 현황에서는 미션별로 작가 목록과 제출 여부를 확인할 수 있습니다.

미션 번호는 전체 미션을 기준으로 1번부터 자동 증가하며, 제출 시작일과 마감일로 실제 제출 가능 기간을 관리합니다.
기존 주차 데이터는 마이그레이션 시 제출 시작일 순으로 미션 번호를 다시 부여합니다.

## 작가 링크와 삭제

작가 등록·수정 화면에서 플랫폼별 URL을 여러 개 저장할 수 있습니다. 기존 SNS 계정/아이디 값은 호환성을 위해 별도로 보존됩니다.
작가 삭제 시 해당 작가의 제출 내역과 등록된 플랫폼 링크도 함께 삭제됩니다.

## 보안 참고

- `.env`는 커밋하지 않습니다.
- 작가 비밀번호는 bcrypt 해시로 저장합니다.
- 개발용 세션 저장소는 메모리 기반입니다. 외부 운영 배포 시에는 파일/DB 세션 저장소로 교체해야 합니다.
